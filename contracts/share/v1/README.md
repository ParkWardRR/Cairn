# Trip sharing v1 (reserved)

Reserved for a portable trip format with redaction metadata: a trip the owner chooses to
send to someone else, with start, end and saved places blanked on request.

**Nothing is designed here.** The threat model gets a sharing section first (what leaves the
house, who can see it, how a redaction is proven), and only then a format. A trip's
identity must stay stable across export and import, so trip ids are not to be changed
before that design.

- **Status:** reserved, draft.
